# Gold SMC Agent 🥇

Agent يحلل سوق الذهب (XAUUSD) بمنهج Smart Money Concepts، ويبعت الصفقات مع أسبابها على بوت تلغرام — تلقائياً كل 15 دقيقة، مجاناً بالكامل، من غير أي سيرفر أو كمبيوتر بتاعك.

## الطريقة: GitHub Actions (مجاني ومن التلفون بالكامل)

**GitHub** هو موقع بيستضيف الكود، وعنده خاصية اسمها **Actions** بتشغّل الكود بتاعك تلقائياً وبشكل دوري على سيرفراتهم — مجاناً. مش هتحتاج تفتح كمبيوتر ولا تكتب أي أمر؛ كل حاجة هتتعمل بالضغط على أزرار من متصفح تلفونك.

### الخطوة 1: اعمل حساب GitHub
افتح https://github.com من متصفح تلفونك واعمل حساب مجاني (إيميل + باسورد).

### الخطوة 2: اعمل "Repository" جديد وارفع الملفات
1. بعد تسجيل الدخول، اضغط على **+** فوق يمين الشاشة → **New repository**.
2. اكتب اسم زي `gold-smc-agent`، سيبه **Public**، واضغط **Create repository**.
3. جوه الـ repository الفاضي، اضغط **Add file → Upload files**.
4. ارفع كل الملفات اللي بعتهالك (كل ملفات الـ `.py` و `requirements.txt` و `README.md`)، وكمان مجلد `.github` بكامله (فيه ملف الجدولة).
5. اضغط **Commit changes** تحت الصفحة.

> ⚠️ **مهم**: متعملش رفع لملف `.env` أو `.env.example` فيه بيانات حقيقية — إحنا هنحط البيانات الحساسة بطريقة آمنة في الخطوة الجاية، مش في الملفات نفسها.

### الخطوة 3: حط بياناتك السرية بأمان (Secrets)
عشان التوكنات بتاعتك متبقاش ظاهرة لأي حد (مع إن الـ repo عام):
1. من صفحة الـ repository، روح **Settings** (تحت في القائمة، ممكن تحتاج تدوس على الثلاث نقط ⋯ لو الشاشة صغيرة).
2. من القائمة الجانبية: **Secrets and variables → Actions**.
3. اضغط **New repository secret** وضيف كل واحدة من دول لوحدها (الاسم بالظبط زي ما هو، والقيمة بتاعتك):

| الاسم (Name) | القيمة (Secret) |
|---|---|
| `DERIV_APP_ID` | `1089` |
| `DERIV_API_TOKEN` | التوكن اللي جبته من Deriv |
| `TELEGRAM_BOT_TOKEN` | توكن بوت التلغرام من BotFather |
| `TELEGRAM_CHAT_ID` | الـ chat id بتاعك من @userinfobot |

### الخطوة 4: شغّله أول مرة يدوياً للتجربة
1. روح تبويب **Actions** فوق في صفحة الـ repository.
2. هتلاقي "Gold SMC Signal Check" — دوس عليه.
3. دوس **Run workflow** (زرار على الشمال) → **Run workflow** تاني للتأكيد.
4. استنى دقيقة أو اتنين وحدّث الصفحة — لو الدائرة ظهرت خضرا ✅ يبقى اشتغل تمام، ولو حمرا ❌ دوس عليها تشوف رسالة الخطأ (ابعتهالي وأنا أساعدك).

بعد كده هيشتغل لوحده تلقائياً كل 15 دقيقة، وأي إشارة تداول تتحقق شروطها هتوصلك على تلغرام فوراً — من غير ما تفتح حاجة خالص.

## طريقة عمل التحليل (Top-Down)

1. **H4** → تحديد التحيز العام (BOS / CHoCH)
2. **H1** → تحديد منطقة Premium / Discount
3. **M5** → كشف Liquidity Sweep + تأكيد CHoCH
4. **M1** → الدخول عند رجوع السعر لـ Order Block أو Fair Value Gap

## هيكل الملفات

| الملف | الوظيفة |
|---|---|
| `config.py` | تحميل الإعدادات |
| `deriv_connector.py` | جلب بيانات السعر من Deriv API |
| `smc_analysis.py` | منطق SMC: Structure, Liquidity, Order Blocks, FVG |
| `signal_engine.py` | يجمع التحليل Top-Down ويطلع قرار الصفقة |
| `telegram_notifier.py` | إرسال الإشارات على تلغرام |
| `run_once.py` | نقطة التشغيل اللي بيستخدمها GitHub Actions (فحص مرة واحدة في كل تشغيلة) |
| `main.py` | نسخة بديلة بحلقة تشغيل مستمرة — تستخدم لو شغّلت الكود على جهازك/سيرفر بنفسك بدل GitHub Actions |
| `.github/workflows/gold_signal.yml` | ملف الجدولة اللي بيقول لـ GitHub يشغّل الكود كل 15 دقيقة |

## ملاحظات مهمة

- الكود الحالي **تحليلي فقط** — بيبعت إشارات، ومش بيفتح صفقات فعلياً في الحساب. ده قرار متعمد للأمان.
- الفحص كل 15 دقيقة (مش كل ثواني) — ده أقصى استقرار ممكن مع الخيار المجاني. لو حبيت سرعة أعلى لاحقاً، الحل هو سيرفر صغير (VPS) بيشغّل `main.py` باستمرار.
- ممكن يحصل تكرار لنفس الإشارة أكتر من مرة لو السعر فضل داخل نفس منطقة الدخول لفترة، لأن كل تشغيلة على GitHub Actions مستقلة ومالهاش ذاكرة بالتشغيلة اللي قبلها (بعكس `main.py` اللي فيه نظام cooldown).
- الأرقام في `smc_analysis.py` (زي `avg_range * 1.5` أو `left/right = 3`) دي قيم بداية معقولة وهتحتاج تتظبط بعد ما تشوف نتائج حقيقية على الشارت.
- ينصح تراقب الإشارات فترة على حساب **Demo** قبل أي اعتماد حقيقي عليها.
